##STRING CITY

##About the Project

STRING CITY is an interactive educational game developed using Python and Pygame to make learning Python fundamentals and Data Structures and Algorithms (DSA) more interesting and engaging.
The project follows a game-based learning approach, where students learn programming concepts by solving interactive challenges and completing different levels.
The current module, STRING CITY, focuses on Strings in Python. Players learn string concepts through challenges, hints, XP, lives, and a final String Boss challenge.
The project is designed with the goal of gradually expanding the game with more Python and DSA concepts in future modules.

##Features

##How to Run

1. Install Python

Make sure Python is installed on your computer.

2. Install Pygame

Open the terminal and run:

pip install pygame

3. Clone or Download the Repository

Download this repository to your computer or clone it using Git.

4. Run the Game

Open the project folder in VS Code or a terminal and run:

python string_city.py

##How to Play
1. Start the game.
2. Select a learning challenge from STRING CITY.
3. Read the question and solve the challenge.
4. Enter your answer.
5. Use hints when required.
6. Earn XP for correct answers.
7. Manage your lives carefully.
8. Complete all four learning modules.
9. Defeat the String Boss to complete STRING CITY.

##Project Objective
The main objective of STRING CITY is to provide a simple, interactive, and engaging way to learn Python fundamentals and DSA concepts.
Instead of learning programming concepts only through theory, students can practice them through game-based challenges, problem-solving activities, hints, rewards, and interactive feedback.
